# Reporting security issues

Send private reports to `trungkien.nt92@gmail.com` with the affected source
revision, the invariant involved, a local reproduction and the observed impact.
Please avoid including live credentials or third-party account data.

This repository is an unaudited local prototype. Its deterministic LEZ account
material is public test-fixture data and must not secure assets. Fresh member
signing keys are created outside the checkout and are not included in the evidence.
There is no production deployment or custody service associated with this release.

No paid bug-bounty programme or reward commitment is offered by this repository.
